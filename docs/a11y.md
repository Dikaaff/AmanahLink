# Aksesibilitas — NFR-06 (WCAG 2.1 AA)

Terakhir diverifikasi: **2026-11-04**.

## Alat dan cakupan

- `@axe-core/playwright` **4.14.0** (dev dependency, tidak masuk bundle produksi).
- Playwright Chromium (channel `chrome`) terhadap stack lokal: Next.js dev
  server + Laravel `artisan serve` + fixture `MccCodeSeeder`/`DemoSeeder`.
- Aturan yang dijalankan: tag `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`.
- Halaman yang dipindai:
  - `/` (beranda)
  - `/login`
  - `/register`
  - `/dashboard` sebagai campaigner `budi@amanahlink.test`

## Hasil

```text
npx playwright test tests/e2e/a11y.spec.ts
4 passed (2.3m)
```

Keempat halaman menghasilkan **0 pelanggaran** pada semua level (tidak hanya
serious/critical), sehingga klaim otomatis untuk halaman tersebut adalah
**lulus WCAG 2.1 AA versi axe**. Test `tests/e2e/a11y.spec.ts` sekarang
meng-assert `violations === []`, jadi regresi otomatis menggagalkan CI.

## Batas bukti

- Belum mencakup `/admin/*`, `/campaigns/[slug]`, `/notifications`, halaman
  form kampanye, dan alur donasi. Tambahkan path saat halaman tersebut berubah.
- axe hanya menangkap pelanggaran yang bisa dideteksi otomatis; uji keyboard
  manual (urutan fokus, escape pada dialog, visible focus) dan pembaca layar
  tetap wajib sebelum klaim penuh NFR-06.
- Kanal browser hanya Chrome; Firefox/WebKit belum diukur.
- CI (.github/workflows/ci.yml) belum menjalankan Playwright/axe; jalankan
  `npm run e2e` di job terpisah saat browser runner tersedia.
